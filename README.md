# Resume Genie AI

AI Resume Builder + ATS Checker - Product Requirements Document (PRD)

1. Project Overview

The AI Resume Builder + ATS Checker is a web-based application that helps users create professional resumes using Artificial Intelligence and evaluate their resumes against Applicant Tracking Systems (ATS). The platform generates optimized resumes based on user input and provides ATS compatibility scores with improvement suggestions.

2. Problem Statement

Many job seekers face challenges in creating professional resumes, formatting them correctly, passing ATS screening systems, matching resumes with job descriptions, and identifying missing skills and keywords.

3. Objectives

Primary: Generate professional resumes automatically, analyze ATS compatibility, provide keyword optimization suggestions, and improve job application success rates. Secondary: Save multiple resume versions, offer downloadable templates, and match resumes with job descriptions.

4. Target Users

Students, freshers, job seekers, career switchers, HR professionals, career coaches, and recruitment agencies.

5. Key Features

AI Resume Builder, ATS Checker, Job Description Matching, and Resume Export (PDF/DOCX).

6. Functional Requirements

User registration/login, profile management, resume creation/editing/download, AI content generation, ATS scoring, resume parsing, and recommendation engine.

7. Non-Functional Requirements

Fast performance, secure authentication, scalability, and mobile-friendly usability.

8. Technology Stack

Frontend: React.js, Backend: Node.js/Express.js, Database: MongoDB, AI: OpenAI/Gemini API, Authentication: JWT, Storage: AWS S3/Cloudinary, Deployment: AWS/Vercel.

9. System Workflow

User Registration → Enter Resume Details → AI Generates Resume → ATS Analysis → ATS Score → Suggestions → Resume Improvement → Download.

10. Expected Outcomes

Professional ATS-friendly resumes, improved interview shortlisting chances, and faster job application processes.

Conclusion

The platform combines AI-powered resume generation and ATS analysis to help users create recruiter-friendly resumes and improve career opportunities.
